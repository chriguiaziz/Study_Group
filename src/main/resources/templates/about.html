About StudyGroup

StudyGroup is a Spring Boot MVC application built to demonstrate object-oriented programming, relational database design, and modern user interface design.

OOP Concepts

Abstract base entities, a profiled user superclass, polymorphic learning resources, reusable service contracts, method overriding, and method overloading.

Architecture

Clean packages for controllers, services, repositories, DTOs, models, enums, configuration, web helpers, and utilities.

Features

Registration, login, dashboard, CRUD groups, join/leave, chat, shared resources, notifications, profiles, settings, search, and responsive pages.
